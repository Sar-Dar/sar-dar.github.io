# Personal academic website

Open `index.html` in a browser. This is a static site and does not require a build step.

Edit `index.html` to update the biography, news, publications, and other content. Edit `styles.css` to adjust the layout and appearance. The portrait is in `assets/`, and `tutorial/` contains the supplied tutorial website.

Before publishing, review the current Ph.D. and internship status. The local source materials do not establish a definitive end date for the internship. The Latent Softmax entry is described as accepted because final proceedings details were not available in the supplied materials. The CTC-TTS entry was omitted because its supplied publication link did not match the paper.

The locally bundled Font Awesome font is used for the profile icons (Font Awesome 4, SIL Open Font License 1.1).
